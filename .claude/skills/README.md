# Carpeta de skills

Esta carpeta es opcional. Dos formas de usarla — ver la sección 6b de la guía
(`docs/PLANTILLA-PROYECTO-CLAUDE.md`) antes de crear nada aquí:

- **Solo referencia**: notas o procedimientos que tú o Claude leen manualmente. No
  requiere nada especial, pero Claude tampoco la detecta ni la invoca solo.
- **Skill invocable de verdad**: cada una necesita su propia carpeta con `SKILL.md`
  y frontmatter obligatorio (`name` + `description`), para que Claude decida activarla
  solo según la situación.

Borra este README cuando agregues tu primera skill real.
